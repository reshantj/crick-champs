# Crick Champs — Scoreboard presentation update

- Public spectator page redesigned as a clean live match scoreboard.
- Removed ball-by-ball commentary from the public spectator view.
- No win-probability display.
- Shows innings, batting/bowling teams, current batter names, bowler, runs, wickets, overs and extras.
- Public page remains read-only and does not require spectator login.

This is a presentation update to the existing live-scoring foundation, not certification of a complete Laws-of-Cricket scoring engine. Verify the database migration and run real-match test cases before production use.
